Secuenciación Sanger / Cell Line ID
Sanger · Cell Line ID

Autenticación de líneas celulares por perfil STR.

Autenticación de líneas celulares humanas con kit PowerPlex Fusion 6c en ABI 3730xl. Los perfiles STR se comparan contra las bases de referencia ATCC y Cellosaurus según el estándar internacional ICLAC.

Solicitar cotización Ver Sanger →
Para quién

Requisito editorial, seguro de laboratorio.

Crítico para investigadores que publican en revistas que exigen autenticación de líneas celulares (Nature, Cell, Cancer Research, entre otras), validación de bancos celulares institucionales y detección de contaminación cruzada.

99,99% de precisión · TAT 3–4 días hábiles · reportes válidos para publicación

Tipos de reporte

1. STR Profiles individual — perfiles de cada muestra sin comparación.
2. Cliente vs base de referencia — matching score contra ATCC, Cellosaurus o ambas.
3. Cliente vs cliente — comparativa entre muestras del mismo cliente.
4. Cliente vs muestra previa — frente a pedidos anteriores.
Interpretación ICLAC 0–55% match → líneas no relacionadas (donantes distintos)
56–79% match → indeterminado, requiere más loci
80–100% match → líneas relacionadas (mismo donante)

Requisitos de muestra

ADN≥ 10 ng/µL · ≥ 200 ng total
Pellet celular> 10.000 células · con tarifa de extracción
Tejido> 20 mg · envío con hielo seco · con tarifa de extracción
Sangre> 2 mL · envío con hielo seco · con tarifa de extracción
FFPENo procesable — usa NGS dirigido
InstrumentoABI 3730xl + PowerPlex Fusion 6c
TAT3–4 días hábiles
